# String Tasks

Практические задания: работа со строками и f-строками на Python.

## Требования

- Python 3.8+

## Задания

| № | Файл                      | Описание                   |
|---|---------------------------|----------------------------|
| 1 | `task1_reverse_vowels.py` | Разворот гласных в строке  |
| 2 | `task2_initials.py`       | ФИО → Ф.И.О.               |
| 3 | `task3_find_target.py`    | Подсчёт вхождений символов |
| 4 | `task4_last_word.py`      | Длина последнего слова     |
| 5 | `task5_day_month.py`      | Дата → «5 jan»             |
| 6 | `task6_day_of_year.py`    | Номер дня в году           |
| 7 | `task7_min_sum.py`        | Минимальная сумма пар цифр |

## Запуск

```bash
python3 task1_reverse_vowels.py
```

## Пример

```
Введите строку: hEllo WOrld
hOllo WErld
```
